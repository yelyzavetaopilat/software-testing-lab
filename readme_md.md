# Практична робота №3: Створення автоматизованого тесту за допомогою штучного інтелекту та публікація коду на GitHub

## 1. Загальна інформація
* **Назва роботи:** Створення автоматизованого тесту з використанням Playwright та публікація коду на GitHub.
* **Протестований вебсайт:** [Riot Games (English)](https://www.riotgames.com/en)
* **Інструмент штучного інтелекту:** Google Gemini (використано для генерації початкового тестового скрипту та налагодження локаторів).
* **Стек технологій:** Node.js, JavaScript, Playwright Test runner.

---

## 2. Опис автоматизованих перевірок (3 тест-кейси)
Скрипт у файлі `riot.spec.js` виконує такі автоматизовані перевірки:

1. **Перевірка успішного відкриття сайту та заголовка (Title Check):**
   * Переходить за адресою `https://www.riotgames.com/en`.
   * Перевіряє, чи містить заголовок сторінки текст `"Riot Games"`.
2. **Перевірка наявності елемента навігації (DOM Visibility Check):**
   * Знаходить панель навігації (`<nav>`) на головній сторінці.
   * Перевіряє, що елемент є видимим для користувача на екрані.
3. **Перевірка інтерактивності та переходу між сторінками (Click & Navigation Check):**
   * Знаходить інтерактивне посилання "Who we are" у меню.
   * Виконує автоматичний клік по посиланню.
   * Перевіряє, що новий URL сторінки змінився та містить `/who-we-are/`.

---

## 3. Інструкція із запуску тесту

### Передумови
На комп'ютері мають бути встановлені:
* **Node.js** (версії 16+)
* Браузер **Google Chrome**

### Покроковий запуск:
1. Клонуйте репозиторій або завантажте його вміст у локальну папку.
2. Відкрийте термінал у папці проєкту та встановіть залежності:
   ```bash
   npm install
   ```
3. Запустить автоматизоване тестування:
   ```bash
   npx playwright test riot.spec.js
   ```
4. Для запуску тесту у видимому режимі (з показом вікна браузера):
   ```bash
   npx playwright test riot.spec.js --headed
   ```
